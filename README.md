# ☁️ Weather App

A simple, clean, and responsive Weather App built using **HTML**, **CSS**, and **JavaScript**.  
It fetches real-time weather data using a public Weather API — no backend required!

🌐 **Live Preview**: [Weather App](https://amit7976.github.io/Weather-App/)

---

## 🧠 Features

- 🌤️ Get real-time weather updates by city name  
- 🌡️ Displays temperature, humidity, wind speed, and conditions  
- 📱 Mobile-friendly design  
- ⚡ Fast and lightweight — runs entirely in the browser  
- 🔗 Powered by a public Weather API

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- weatherapi's API

---

## 📌 Notes

- No backend used — everything works in-browser
- Ideal for learning how to use APIs in frontend-only apps
